# Release notes template / الگوی یادداشت انتشار

Use this text when creating a GitHub **Release** and attaching the APK from Actions.

این متن را هنگام ساختن **Release** در گیت‌هاب و ضمیمه کردن APK از Actions استفاده کنید.

---

## English

**Telegram Accessible (TalkBack) — arm64**

- Accessibility-focused build of Telegram Android (not official Telegram)
- Package ID: `com.shamloo.telegram.accessible` (can sit next to the store app)
- Built with GitHub Actions; artifact name: `telegram-accessible-arm64`
- TalkBack: name-then-type chat list, less clutter between messages, progress percent, long-press menu, Select / Reactions / Bot buttons from the menu, labeled settings controls, FA/EN via LocaleController
- Smaller APK: **arm64-v8a only** (modern phones)
- GPL-2.0 patches on [DrKLO/Telegram](https://github.com/DrKLO/Telegram). Respect Telegram API Terms when redistributing.

---

## فارسی

**تلگرام دسترس‌پذیر (TalkBack) — arm64**

- بیلد متمرکز بر دسترس‌پذیری از تلگرام اندروید (رسمی نیست)
- شناسه پکیج: `com.shamloo.telegram.accessible` (می‌تواند کنار اپ فروشگاه نصب شود)
- ساخته‌شده با GitHub Actions؛ نام artifact: `telegram-accessible-arm64`
- TalkBack: نام بعد نوع در لیست چت، کمتر شدن آشغال بین پیام‌ها، درصد پیشرفت، منوی long-press، Select / Reactions / دکمه‌های ربات از منو، برچسب تنظیمات، فارسی/انگلیسی با LocaleController
- حجم کمتر: فقط **arm64-v8a** (گوشی‌های جدید)
- پچ‌های GPL-2.0 روی [DrKLO/Telegram](https://github.com/DrKLO/Telegram). هنگام نشر مجدد، شرایط API تلگرام را رعایت کنید.
